# Certificado raíz de Supabase

Aquí va el archivo `supabase-ca.crt`: el certificado raíz que Supabase publica
para verificar la conexión cifrada con la base. Se descarga desde el panel del
proyecto, en Database Settings, sección SSL Configuration, y se guarda con ese
nombre. Es un certificado público: no contiene ninguna llave privada.
